Official User Guide

MagnetoClip User Manual

Comprehensive documentation covering setup, activation, download acceleration, browser extensions, torrents, remote control, and system architecture.

1. Getting Started

MagnetoClip is a Windows desktop download manager that captures files, videos, music, documents, and torrents from the web into smart, auto-sorted categories. It pairs an IDM-class multi-connection download core with a companion browser extension that detects downloadable content in real time as you browse.

System Requirements

  • Operating System: Windows 10 or Windows 11 (64-Bit editions).
  • Network: An active internet connection for multi-chunk downloads and stream capture.
  • License: A valid serial key (release builds only — development builds skip licensing).

Starting the App

Launch MagnetoClip from the Windows Start menu or desktop shortcut. A splash screen appears while the application initializes local SQLite databases and network engines, after which the main window opens on the Overview page.

First Launch Activation
If you started MagnetoClip for the first time, you will be prompted to activate your serial license key before accessing the main window.

2. Activating Your License

Each serial key binds cryptographically to one PC. License keys follow the Ed25519 standard format:

MGCL-XXXXX-XXXXX-XXXXX-XXXXX

Step-by-Step Activation

  1. When the Activate MagnetoClip dialog appears, paste or type your serial key. Extra spaces, hyphens, and lowercase characters are normalized automatically.
  2. Click Activate.
  3. On success, the application unlocks immediately. The PC's unique machine ID is recorded by the license server, binding this computer as the authorized hardware.
  4. If the key is already bound to another PC, the dialog displays the specific hostname holding the activation. Deactivate it on that machine first (Settings → License → Deactivate this PC…) or contact support to request a reset.

License Activation Messages Reference

Status Message Meaning & Recommended Action
Could not reach the license server Check your internet connection and proxy settings, then retry.
This serial key has been revoked The license key was disabled by the vendor — contact customer support.
This serial key has expired The subscription term has concluded — renew your plan to continue.
That serial was not recognized Typographical error in the serial key — re-check the email receipt.
Too many attempts Rate-limiting safety triggered — wait approximately 60 seconds and retry.
OS Credential Store Security
Your serial key is stored securely in the Windows Credential Manager (OS Keyring) — never in plaintext configuration files. On subsequent launches, MagnetoClip silently validates the signed token against the server.

Moving Your License to Another PC

To migrate your license to a new PC: open Settings on the current machine, scroll down to License, and click Deactivate this PC…. This frees your slot immediately on the license server so your key can be used on the new computer.

3. Interface Tour

The top toolbar switches between pages, while the collapsible left sidebar filters the download workbench. Use the ☰ toggle button to collapse the sidebar for extra screen workspace.

Overview Page

A real-time command dashboard featuring four live stat cards (Active downloads, Completed, Total downloaded, Current speed) plus up to five recent transfer cards with dynamic progress bars, throughput speeds, and time estimates (ETAs).

Downloads Workbench

The central management hub. Each item row displays filename, file size, segmented color progress bar, percentage, speed, remaining time, and addition timestamp.

Toolbar Controls: Select All · Add · Start · Pause · Remove

Context Menu Actions (Right-Click Row):

  • Completed downloads: Open File, Open File Location (reveals in Windows Explorer), Restart Download.
  • Failed downloads: Retry Download (re-engages multi-connection chunks).
  • Active / Paused / Queued: Pause / Resume / Start immediately.
  • Universal actions: Copy Source URL, Remove from List.

Double-clicking any download row opens the Download Details modal with full segment telemetry, connection status, and manual overrides.

Sidebar Filter Categories:

Filter by All Downloads, Finished, Unfinished, or any of the 8 smart categories: Image, Video, Audio, Document, Compressed, App/Software, Torrent, Other. Real-time counter badges show exact matching item counts.

Detected Page

Gathers all multimedia files and stream links detected by the browser extension: filename, size, MIME type, source URL, and timestamp. Select items and click Download, or double-click to start immediately.

Completed Page

A focused historical archive containing only finished, failed, or stopped downloads for rapid search and opening.

Analytics Page

Six comprehensive telemetry cards (total files, completed, failed, data transferred, average speed, peak speed), two 14-day history bar charts (Downloads per day & Bandwidth per day), and a full per-category storage breakdown — all calculated 100% locally.

4. Adding Downloads

Click the Add button on the Downloads page (or paste directly from clipboard).

New Download Dialog Fields

Dialog Field Description & Supported Inputs
URL Accepts standard http://, https://, internal browser blob:, and magnet: URIs.
Filename Optional custom name (retains server-provided name if left blank).
Save to Target folder (defaults to your configured download path or category subfolder).
Category Pre-selected automatically based on file extension matching rules.
Connections Allocates 1 to 64 parallel TCP connection segments for this transfer.
Proxy profile Route download through a saved proxy configuration or Direct.
Username / Password Optional HTTP Basic-Auth credentials (stored securely in Windows Credential Manager).
Cookies Custom header-style cookies (e.g. session_id=xyz789; token=abc).

Understanding blob: URLs

Browser-Exclusive Blob Fetching
Right-clicking and copying link addresses on modern web video players often produces blob:https://... addresses that only exist in browser memory. When the MagnetoClip companion extension is installed, the app requests the raw stream bytes directly through native messaging — simply keep the source browser tab open until the transfer finishes.

Multi-Segment Resilience & Sidecars

Transfers are split into byte ranges fetched simultaneously. State is recorded continuously in a .mclip JSON sidecar file. If your machine restarts or experiences connection loss, downloads resume from the exact byte offset without wasting bandwidth.

Download Status Flow: Queued → Scheduled → Connecting → Downloading → Paused → Retrying → Verifying → Completed (or Failed / Verification Failed).

5. Browser Integration

The Manifest V3 companion extension bridges MagnetoClip with your web browsers via Chrome Native Messaging to detect media, intercept links, and capture chunked streams.

Supported Browsers: Google Chrome, Microsoft Edge, Mozilla Firefox, Brave, Vivaldi, and Chromium.

Setup Instructions

  1. Open the Browser page in MagnetoClip and tick Enable browser integration.
  2. Under Installed browsers, locate your browser and click Install host (registers the native messaging registry key).
  3. Under Browser extension, click Prepare extension and load it:
    • Chrome / Edge / Brave / Vivaldi / Chromium: Open chrome://extensions, enable Developer mode, click Load unpacked, and select the extension folder shown on the screen.
    • Firefox: Open about:debugging#/runtime/this-firefox, click Load Temporary Add-on, and select the extension manifest file.
  4. The status indicator at the bottom turns Green when connected.

Capture Modes & Settings

Option Functionality
Enable browser integration Master toggle for the native messaging bridge.
Capture media streams Detects embedded video and audio streams as pages load.
Make MagnetoClip default downloader Intercepts all browser download requests and passes them to the acceleration engine.
Show confirmation dialog Displays a popup prompt before queuing captured media.
Notify when files are found Fires Windows tray notification balloons upon detection.

When a file is intercepted, the Downloadable File Detected popup offers four quick actions: Download now, Download later (queues to list), Skip, or Skip all (suppresses alerts for 1 hour or permanently).

6. Capturing Files and Streaming Media

MagnetoClip recognizes over 100 extensions across 10 media categories and automatically sorts them into dedicated folders when Auto-categorize by file type is enabled.

Embedded yt-dlp & FFmpeg Bridge

Streaming services are processed through a dedicated engine supporting dozens of video and music platforms, alongside direct HTTP Live Streaming (.m3u8) and Dynamic Adaptive Streaming over HTTP (.mpd) manifests.

Streaming Quality Selector
Select your preferred global quality under Settings → Streaming media quality:
  • Best Available: Downloads highest available video resolution and bitrate.
  • 1080p Full HD: Caps video resolution at 1920×1080.
  • 720p HD: Optimizes bandwidth with standard high definition.
  • Audio Only: Extracts audio track directly into MP3/AAC container.

Separate audio and video DASH streams are multiplexed automatically by the bundled FFmpeg binary into a single synchronized container with metadata intact.

7. Torrents (libtorrent Client)

The dedicated Torrents page provides complete BitTorrent capability without requiring third-party clients.

Adding Torrents

  • Add Magnet: Paste a magnet URI (magnet:?xt=urn:btih:...) or .torrent URL.
  • Upload File: Select a local .torrent file from disk.
  • Metadata Preview: Displays torrent name, total size, tracker list, info hash, and full interactive file selection tree.

System Protocol Registration

Register MagnetoClip as your default handler in Settings → Torrent:

  • Register to open .torrent files: Double-clicking .torrent files in Windows opens MagnetoClip.
  • Register magnet: links: Clicking magnet links on web pages launches the download dialogue.

8. Remote Dashboard (Port 8477)

Control and monitor your downloads from a smartphone, tablet, or secondary PC on the same local network.

Remote Control Setup 
1. Open Settings -> Remote Control
2. Tick "Enable remote dashboard" (Default port: 8477)
3. Click "Show QR..." and scan with your phone camera
4. Authenticate using the generated Bearer + HMAC token

Clicking Regenerate Token instantly revokes all paired mobile devices. The remote web application runs on a lightweight Python aiohttp server and never exposes local files or credentials outside the network.

9. Proxy Profiles

Manage multiple proxy servers under Settings → Proxy → Manage proxy profiles…:

  • Protocol Support: HTTP, HTTPS, and SOCKS5.
  • Credentials: Usernames and passwords are encrypted in the Windows Credential Manager keyring — never stored in plaintext SQLite databases.
  • Routing: Set a global default proxy or choose a specific profile per individual download in the Add dialog.

Updates Engine

MagnetoClip periodically queries the secure update endpoint. Press Check Now in Settings to trigger a manual check. Updates are downloaded, verified with SHA-256 signatures, and applied automatically with an application restart.

11. System Tray

MagnetoClip minimizes to the Windows taskbar notification area (System Tray). Hovering over the icon displays active download counts and aggregate throughput speed.

Tray Context Menu:

  • Open MagnetoClip: Restores main window.
  • Pause All / Resume All: Global transfer state override.
  • Open Remote…: Displays mobile pairing QR code.
  • License…: Displays masked key and validation status.
  • Exit: Terminates engines and saves all .mclip sidecars.

Clicking a finished download notification balloon reveals the downloaded file directly in Windows Explorer.

13. Troubleshooting

Quick solutions to common configuration and networking questions:

The app asks for a serial key on every start
Verify your internet connection; the desktop application must reach the license server to validate the bound machine token. If the network is operating normally, re-enter the serial key once to refresh the Windows Credential Manager entry.
"Verification failed" error on a completed download
The transferred file checksum (MD5/SHA-256) did not match the manifest supplied by the server. Right-click the download item and choose Retry Download to re-fetch corrupted chunks.
Blob URL download hangs at 0%
blob: resources reside inside the active browser tab memory. Keep the source browser tab open until the native messaging transfer reaches 100%.
Browser extension is not detecting media files
In MagnetoClip, navigate to the Browser page and ensure: (1) Browser integration is enabled, (2) Host is installed for your browser, (3) Extension is loaded, and (4) The status dot is Green. Afterward, reload the target web page.
BitTorrent transfers show zero connected peers
Enable DHT and PEX under Settings > Torrent. Verify that incoming TCP/UDP port 6881 is permitted through Windows Defender Firewall and router NAT rules.
Remote dashboard unreachable from smartphone
Ensure both your PC and phone are connected to the same Wi-Fi network. Check that the port (8477) server status shows Running in MagnetoClip, then scan a fresh QR code after regenerating the token.
Forgot which PC holds my license key
The activation error message names the specific bound hostname. Deactivate the license on that computer under Settings > License, or contact support@magnetoclip.app to request a machine binding reset.
